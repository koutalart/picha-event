# PICHA Event

Plateforme de gestion événementielle **multi-organisateurs**, avec espaces privés, événements, équipes, missions, échéances, prestataires, commentaires et documents.

**Statut :** cadrage du MVP et audit de Plane. Aucun déploiement applicatif à ce stade.

## Principes
- Chaque organisateur dispose de son espace privé.
- Les accès sont contrôlés côté serveur et testés.
- L'interface est responsive et pensée pour les équipes terrain.
- Plane est un candidat technique à évaluer, non une dépendance imposée.
- Tropikal Xmas 2026 sert de pilote, sans personnalisation codée en dur.
